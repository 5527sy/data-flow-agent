# DataFlow Agent 🏦

> 卡片式人机共驾的数据分析 Agent —— **机器负责算和画，人负责拍板和签字。**

用户用一句自然语言说出分析需求，Agent 自动判断分析范式（分类 / 聚类 / 归因 / 取数），
然后以**向导式卡片流程**带人走完：样本设计 → 取数 → 数据体检 → 清洗与特征工程 → 模型训练 → 名单输出。
每一步：系统给提案和可视化结果，人改参数、看预览、拍板，全程可审计、可回溯。

## ✨ 特性

- **范式路由器**：规则通道 + LLM 通道双裁判，判定一致才放行，低置信度自动转澄清（绝不硬猜）
- **样本设计助手**：观察期 / 表现期 / 正负标签 / 排除规则，先出设计方案人工确认，再生成提数 SQL
- **人机共驾向导**：每步一张卡片（说明 → 参数 → 运行 → 预览 → 拍板），参数带智能默认值，人工只改不满意的
- **结果可预览**：每步产出图表 + 一行 LLM 生成的"人话结论"，人只做判断题，不做阅读理解题
- **全程可审计**：每步决策进审计日志，产物进版本快照，上游参数变更自动让下游结果过期（涟漪过期）
- **规则固化重放**：训练期的清洗 / 分箱 / 编码规则固化为 pipeline，打分期原样重放，保证口径一致

## 🗺 业务流程

```
① 需求路由 → ② 样本设计 → ③ 取数上传 → ④ 数据体检
            → ⑤ 清洗特征 → ⑥ 训练评估 → ⑦ 名单输出
```

## 🏗 架构

```
交互层（卡片式向导 UI）
   │  结构化消息协议（每步一个"提案卡片"）
应用层（Agent 编排）
   │  路由器 / 样本设计 / 数据体检 / 特征工程 / 训练评估
   │  LLM（DeepSeek，OpenAI 兼容协议）只做判断与表达，输出过 pydantic 校验
执行层（确定性代码）
   │  pandas / toad(WOE·IV) / LightGBM / XGBoost / scikit-learn / SHAP
产物层
   名单 Excel + 评估图表 + Markdown 分析报告（全程版本快照）
```
